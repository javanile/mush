# build_cache

> **Status: draft** — this package is a work in progress and not yet usable.

Planned package for caching build artifacts across mush build runs,
avoiding redundant recompilation of unchanged sources.

The current implementation is a placeholder that mirrors `build_logger`
behavior (dumping `MUSH_*` variables). The `Manifest.toml` name field also
needs to be corrected to `build_cache`.
