# name_convention

> **Status: draft** — this package is a prototype and not yet usable.

Planned package for enforcing and documenting mush naming conventions for
functions, variables, modules, and packages.

The current `src/lib.sh` contains a hardcoded demo of Rust-style error output
(`code_dumper_error`) left over from early prototyping. The `Manifest.toml`
name also needs to be corrected to `name_convention`.

## Intended scope (future)

- Validation helpers for package/function naming rules
- Linting utilities for shell scripts that follow mush conventions
- Documentation of the naming convention standard
